# 互動網頁：模型知道，實際卻選錯——BERT 與「原、前、舊、老」

LING5006 期末專案的互動成果呈現。純靜態網頁，資料都已內嵌，不需要後端，也不需要安裝套件。

| 檔案 | 內容 |
|---|---|
| `index.html` | 研究網頁：開場動畫、3D 語義塔、辭典語義集合、逐層探測、語義星圖、行為測試、模型 vs. 實際、語境改寫實驗台、時間滑桿、「兩種讀法」（人腦 vs. 機器） |
| `annotate.html` | 人工語義標註闖關：五關（職場身分、時間參照、身分鏈結、評價傾向、華語教學挑戰），每關附華語教學連結 |
| `story.html` | 互動故事「小張的職場三十年」：8 幕職場情境，讀者和 BERT 一起填字 |
| `duel.html` | 「你來填：人類 vs. BERT」填空遊戲（個人模式，10 題） |
| `duel.html#host` | 主持模式（課堂投影用，6 題）：鍵盤 1–4 記票、Shift＋數字減票、T 計時 15 秒、Space 揭曉／下一題、← 上一題 |
| `site.js`、`site.css` | 全站共用：亮版／暗版、中文／English、音效（Web Audio 即時合成，無音檔）、開場動畫、人腦 vs. 機器元件 |
| `i18n.js` | 英文介面文字；英文版中的中文詞語自動加上漢語拼音 |

## 介面設定（右上角，子頁在右下角）

- **亮版／暗版**：亮版為淺藍色，設定會記住。
- **中／EN**：英文介面；也可用網址參數 `?lang=en` 直接分享英文版。
- **音效開／關**：打字、科技運算、答對（和弦＋掌聲喝采）、答錯、拉桿等音效。
- **開場**：重播開場動畫（首次進站自動播放，可按「略過開場」或 Esc 跳過）。
- 系統若開啟「減少動態效果」，動畫會自動關閉。

## 部署到 GitHub Pages

1. 把本資料夾的所有檔案（含 `.nojekyll`、`site.js`、`site.css`、`i18n.js`）放在 repo 根目錄，push 到 `main`。
2. Settings → Pages → Source 選 *Deploy from a branch*，Branch 選 `main`／`/(root)`，按 Save。
3. 約一分鐘後網址會是 `https://<帳號>.github.io/<repo 名稱>/`。
